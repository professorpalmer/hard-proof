8. A scale test on generated rules

Each run above was accepted on the first visit. That record says little about where the loop stops. This test makes the law set larger until something fails.

The tasks

A generator makes a random decision tree over boolean inputs. Each leaf of the tree becomes one law: "when these inputs have these values, the answer is this". The laws of all leaves are complete. For the second task of each size, the generator removes one law, so a gap exists. The adversary gets the laws and the same brief as before: supply a gap certificate or a completeness proof. The brief does not say which task it has. The sizes are 6 inputs and 8 laws, 10 and 32, 14 and 128, and 18 and 512. These domains have no real code and no link test.

The first set leaked the answer

In the first set, the model file had the reference rule, and the laws had the names Leaf0 to LeafN in tree order. A removed law was a hole in the numbers. One accepted solution says "The law numbered 349 is absent". The first set measures the construction of a large proof, not the search.

The blind set

The blind set has no reference rule. The laws are in random order with the names Law0 to LawN, and the conditions of each law are in random order. The adversary must find from the laws alone if each case has an answer. Each worker could run Python. One fault is in this set: the folder path of each run had the word "gap" or "complete".
